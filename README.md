# 🍿 TixNow - Sistem Informasi Bioskop

Proyek Ujian Akhir Semester (UAS) - Membangun Aplikasi Web Pemesanan Tiket Bioskop menggunakan Laravel 11.

## ✨ Fitur Aplikasi
1. **Otentikasi**: Login & Register Petugas Kasir (Laravel Breeze).
2. **Manajemen Film (CRUD)**: Tambah, Edit, Hapus, dan Lihat data film.
3. **Pemesanan Tiket (Booking)**: Pencatatan transaksi pelanggan.
4. **Auto-Decrement**: Stok tiket otomatis berkurang saat transaksi berhasil.
5. **REST API & Fetch**: Halaman Katalog Publik yang mengambil data film via API menggunakan JavaScript secara asinkron.
